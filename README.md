## 🚀 Featured Project

### [STARTECH — Chandrayaan-2 Image Correspondence](https://github.com/prince8965/Startect)

A mission-control-style web prototype for exploring cross-sensor lunar image registration. The project concept combines image preprocessing, feature detection and matching, geometric verification, transformation estimation, and evaluation visualizations.

**Built with:** Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.
